# Agent Note：Windows 1.0.5 本地试用与发布边界

Status: implemented

[English](2026-09-23-windows-1.0.5-trial.md) | 中文

## 问题

Windows 1.0.5 需要经过真实的本机安装和用户试用，才能确认桌面与托管 Harness 的表现。本地试用验收和公开发布准备是两个决定：已安装产物未签名，签名与 GitHub 发布尚未完成。

## 决策

用户已接受 Windows 1.0.5 本地试用。试用使用了未签名的当前用户 NSIS 与 ZIP 产物，并将托管 Harness 更新到 0.1.5-rc.3。这不代表已签名或公开发布。目前没有可信 Windows 签名证书，因此正式 Windows 发布仍受阻；不得把未签名试用产物称为已签名或已发布。

原始 checkout 及未提交改动、用户 profile、Chat 数据、Memory 数据、cookies 和 sessions 均保留。应用日志记录的手动保留 rc.2 备份删除事件是已确认的试用事故；并非 agent 命令导致。后续 Harness 保留逻辑因此会保留未引用版本目录，而不自动删除。

## 考虑过的替代方案

**把未签名安装器作为正式 Windows 版本发布。** 不采用，因为目前没有可信签名身份，且用户要求发布签名产物。

**把 synthetic boot 或成功打包视为等同于本地试用。** 不采用，因为用户实际体验了安装后的应用并接受了试用；若干具体流程仍未验证，已在下文记录。

## 影响

Windows 本地试用已获接受，其证据可供后续维护参考。签名、上传、tag 和公开 GitHub Release 均未完成。安装器和 ZIP 未签名；npm 暂存安装、Chat 身份验证、托盘/通知边缘行为及若干更新后 UI 操作未由本次试用验证。未引用的托管版本可能占用更多磁盘空间，因为自动删除无法将它们与用户复制的备份区分。
